#### 2-1 データの箱の置き方

- いまの表示の仕組みの `<script>`（453行）の直前に、次の形で**1つだけ**置いてください。中身はJSON（項目名と値を書き並べるデータの書き方）です。

  ```html

  <script type="application/json" id="mochi-data">
  { …ここにJSON… }
  </script>
  <!-- データの箱ここまで -->
  ```
- 表示の仕組みは、ページを開いたときにこの箱を読んで、各区画に数字・文字を入れます。読み方の例：
  ```js
  var D;
  try { D = JSON.parse(document.getElementById('mochi-data').textContent); }
  catch (e) { /* ページ上部に「データの箱を読み込めませんでした（数字は表示していません）」と出す */ }
  ```
- 箱が読めなかったときは、古い数字や仮の数字を出さず、数字の場所は「—」のままにして、ページ上部に「データの箱を読み込めませんでした（数字は表示していません）」と出してください。
- 文字を入れるときは textContent（文字をそのまま入れる方法。記号が混ざってもページが壊れない）を使ってください。
- 別ファイル（data.json など）を読み込む方式は使わないでください。1枚ページ型のSpaceで別ファイルが読めるかどうかが確かめられていないためです（次善の案として残しておきます）。
