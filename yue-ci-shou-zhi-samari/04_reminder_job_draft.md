````markdown
手順1. 正本を読むだけで、最後に入っている月と、まだ入っていない月を確かめる（書き込みはしない）。次をそのまま実行する。

```bash

p = os.path.expanduser("~/workspace/user/files/マネーフォワード家計簿CSV/月次収支データ.json")

    months = json.load(open(p, encoding="utf-8"))["months"]
    last = max(months)
except Exception as e:
    print("読めませんでした:", type(e).__name__, e)
    raise SystemExit(2)
today = datetime.datetime.now(datetime.timezone(datetime.timedelta(hours=9))).date()
prev = today.replace(day=1) - datetime.timedelta(days=1)
want = "%04d-%02d" % (prev.year, prev.month)
y, m, missing = int(last[:4]), int(last[5:7]), []
while True:
    m += 1
    if m > 12:
        y, m = y + 1, 1
    k = "%04d-%02d" % (y, m)
    if k > want:
        break
    missing.append(k)

print("先月:", want)
print("まだ入っていない月:", " ".join(missing) if missing else "なし")
````

## 4. 決めたことと理由

- **先月分がもう入っているときは、聞かずに「済み」と1行だけ伝える**（何も言わない、にはしない）。
  - 理由1：ジョブの結果がいつもチャットに届く作りかどうか（何も言わずに終われるか）は未確認で、「何も言わない」を確実にできるとは限らない。
  - 理由2：1行あれば、ジョブがちゃんと動いていることと、その月が足してあることが本人に分かる。見本の週次ジョブも、変化がないときは「大きな変化なし」と1行で済ませている。
  - 月に1回・1行なので、うるさくない。
- **ページの確かめ（手順2の space_data_check.py）も入れた**：正本だけ新しくなってページが古いまま（02 の手順6・7の途中で止まった）、という状態を見逃さないため。読むだけのスクリプトで、集計スクリプトではない。
- **2か月以上たまっているとき**は全部を並べ、「1か月ずつ順に足します」と添える：02 の照合（append-check）は「正本の最後の月の次の月」だけが増えたかを確かめる作りなので、1か月ずつ足す前提。
- **催促しない**：返事がなければ、次の月の回まで何もしない（依頼どおり）。次の回では、たまった月が全部並ぶ。
- **2027年1月の回**：文面Cで期限（2027-01-20 までに取る）を添える。プレミアムは 2027-01-21 まで（自動更新は停止済み）、無料版ではCSVを取れない（11/15 の調べ）。
- **2027年2月以降の回**：取り方が決まっていないので、「足しますか」とは聞かず、文面Eで「取り方が未定です。決まったらジョブの見直しを」と伝える。本人が取り方を決めたら、もちがジョブを書き直す（ジョブ本文の「このジョブの見直しが要るとき」）。
- 日付の計算は日本時間（＋9時間）で固定。7日の夜なら、ほかの時刻の決め方でも同じ月になる。
