## 2. ファイル名を付けて置く

- 名前：**`家計簿_YYYY-MM.csv`**（例：`家計簿_2026-11.csv`）。年月は「明細の月」。
- 置き場：`~/workspace/user/files/マネーフォワード家計簿CSV/`（121件のCSVと同じフォルダ）。
- **写す（コピー）**。ダウンロードの元のファイルは消さない（あとで突き合わせられるように）。
- 同じ名前のファイルがすでにあれば**上書きしない**で止まる（取り違えの疑い）。
- 写したあと、元のファイルと同じか確かめる：`sha256sum <元のファイル> $CSVD/家計簿_YYYY-MM.csv`

（このフォルダに書き込むのはこの1ファイルの追加だけ。CSVはこの後も変えない。）

## 3. スクリプトで集計・検算・照合（append-check）

```bash
S=~/workspace/audit/space-fixes/yue-ci-shou-zhi-samari
M=2026-11   # 足す月
python3 -I $S/mf_monthly_aggregate_v2.py append-check \
  --out "$S/monthly/$M/月次収支データ_新.json" \
  --report-dir "$S/monthly/$M/照合"
echo "終了コード=$?"
```

このコマンドは、全部のCSVを集計し直して、次を自動で確かめます。
- 全月の検算（自分側の消費＝明細の合計、橋渡し＝口座の増減、収支＝収入＋支出 など）
- **正本にある月（今は121か月）が、1円も・1行も変わっていないこと**
- 増えたのが「正本の最後の月の次の月」だけであること

**合格の条件**：画面に「月の追加の照合：合格」「正本の 121 か月はすべて1円も変わっていません。新しい月：2026-11」と出て、終了コードが 0。
このとき `monthly/2026-11/月次収支データ_新.json`（新しい正本の候補）と、`monthly/2026-11/照合/再現テスト結果_自動.md`（記録）ができます。

**止まったとき**（新しいJSONは作られません。先へ進まない）：

| 画面の言葉 | よくある原因 | どうするか |
|---|---|---|
| 正本にある月で、正本と違うところが ◯ 件ある | 昔の月のCSVを置き換えてしまった | 置き換えたCSVを元に戻す（ダウンロード置き場の元ファイルと突き合わせる） |
| 新しい月がない | ファイル名の付け間違い・置き場所の間違い | 名前と場所を確かめる |
