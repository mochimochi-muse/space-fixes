### 2-2 置き換え後の作り（決まり）

**元にするデータ**：`data.trials`（試行明細）。706行目 `const langMatrix = data ? buildLangMatrix(data.results) : [];` を明細から作る形にする。

1. **外す行**：kind が「人種セル」で始まる行（言語×人種の表にだけ使う）。result が「上限」で始まる行（評価できなかった試行）。
2. **言語のまとめ方**：言語名から「（…）」と末尾の「・標準」を取った名前でまとめる（例：`ソマリ語・標準` → ソマリ語、`中国語（核D）` → 中国語）。今の `baseLanguageName`（125〜127行目）に「・標準」を取る処理を足す形。
3. **並べ方**：
   1. date_label の順（「2026-11-13」の形なので文字の順でよい）
   2. 同じ日の中では試行番号の順。trial_no が数字だけ、または「予備」＋数字（例：`予備38`）のときはその数字
   3. 番号の無い行（`窓プローブA1` や 2026-11-13 の `第1弾-1` など）は、その日の番号つきの行の後ろ
   4. そのあとは sort_order、最後に id
   - この並べ方は、サーバーから届く順番に頼らないよう、画面側で並べ替えてください。
4. **セルの種類**：result が `生成成功` → ○、「部分的通過」を含む → △、それ以外（`生成後ブロック` など）→ ×。
5. **日付の印**：2026-11-14 → †、2026-11-20 → ‡、2026-11-21 → §、それ以外（2026-11-13 を含む）→ 印なし。833〜842行目の `i >= row.nov21From` などの判定を、セルの日付から引く形に変える（`nov14From`・`nov20From`・`nov21From` は不要になる）。
