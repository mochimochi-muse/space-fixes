4. 画面のプログラムの変え方
━━━━━━━━━━━━━━━━━━━━
- var DATA = [ … ] の手書きをやめ、データ部分と表示設定から同じ形の配列を組み立てる。1件ごとに：
  - group：データの group
  - name：表示設定の label（表示設定に無ければデータの name）
  - detail：表示設定の detail（無ければ空の文字）。accounts が2以上なら、その後ろに「（」＋accounts＋「口座合算）」を付ける
  - amount：データの value
  - color：表示設定の color（無ければ fallback_color の区分の色）
- 並び：risk → guard → safe の順。同じ区分の中は value の大きい順（同じ額ならデータの順）。今の表・ドーナツと同じ並びになる。
- total はデータの total、riskTotal・guardTotal・safeTotal はデータの groups.risk.total・groups.guard.total・groups.safe.total を使う（表示するのはデータの値。足し算し直した値との突き合わせは6章の検算で行う）。割合は今の pct・fmtPct のまま、total で割る。ドーナツの角度も value ÷ total。
- 書式（今の表記と同じになるように）：
  - ¥つき：今の yen(n) ＝ "¥" + n.toLocaleString("ja-JP")
  - 円つき：n.toLocaleString("ja-JP") + "円"
  - マイナスの金額：0未満なら "−¥" + (−n).toLocaleString("ja-JP")（先頭の「−」は U+2212。今の表記と同じ文字）。0以上なら yen(n)
  - 日付：date "2026-11-22" → 「2026年11月22日」（月・日の先頭に 0 を付けない）
- 文章の中の数字は、HTML に差し込み口 <span data-asset="名前">—</span> を置き、プログラムで中身を入れる。HTML に最初から書いておく中身は「—」だけ（数字を書かない）。名前は下の5章のとおりにする。
- 出したり隠したりする文は、HTML に文を書いたうえで要素に data-asset-show="名前" と hidden を付けておき、条件に合うときだけ hidden を外す。
- スクリプトのコメントにも、金額・割合・日付・件数を書かない（確認スクリプトがコメントも数えるため）。

━━━━━━━━━━━━━━━━━━━━
(1) 注意の帯を1つ置く
- <div class="wrap"> の直後（topmeta の前）に <div id="dataAlert" class="data-alert" role="alert" hidden></div> を置く。
- CSS を1ルールだけ足す：.data-alert{margin:0 0 12px;padding:12px 14px;border:2px solid var(--risk);background:var(--risk-bg);color:var(--ink);border-radius:12px;font-size:13.5px;font-weight:700;line-height:1.7}
- 問題が無いときは hidden のまま（画面は今と同じ）。問題があるときは hidden を外し、下の文を1つずつ改行（<br>）でつないで入れる。

(2) データが読めないとき
次のどれか1つでも当てはまれば「データが読めない」とします。
- データ部分が無い、または JSON.parse で失敗する、またはオブジェクトでない
- schema_version が 2 でない
- date が "YYYY-MM-DD" の形の文字でない
- total が1以上の整数でない
- groups の risk・guard・safe のどれかが無い、またはその total が0以上の整数でない
- holdings が配列でない、または空、またはどれかの項目で group が "risk"・"guard"・"safe" 以外、name が文字でない、value が0以上の整数でない
- card_liabilities_total が整数でない
- excluded が配列でない、またはどれかの項目で id・name が文字でない、status が "not_in_results"・"excluded" 以外
データが読めないときは：
- 注意の帯に「データを読めません。ページ内のデータ部分が壊れているか、形が想定と違います。」と出す。
- 差し込み口と、合計・区分カードの金額と割合（totalAmt・riskAmt・guardAmt・safeAmt・riskPct・guardPct・safePct・lblRisk・lblGuard・lblSafe）に「データを読めません」と入れる。割合の帯の幅は 0 にする。
- 内訳表の場所（#tables）には <p class="hint">データを読めません</p> だけを入れる。
- ドーナツは背景の輪だけにし、中央の2行目（t2）を「データを読めません」、3行目（t3）を空にする（1行目「合計（ゆうちょ除外）」はそのまま）。
- data-asset-show の文はすべて隠す。
- 数字をそれらしく作って出さない。

(3) 検算（データが読めたとき）
次を確かめ、合わないものがあれば、その文を注意の帯に出す。数字はデータのとおり表示したままにする（隠さない）。
- holdings の value の合計 ＝ total。合わなければ「注意：データの検算が合いません。保有資産の合計 {yen(合計)} と、合計の欄 {yen(total)} が一致しません。」
- 区分ごとに、その区分の holdings の value の合計 ＝ groups.<区分>.total。合わなければ「注意：データの検算が合いません。{リスク資産／守り資産／安全資産}の保有資産の合計 {yen(合計)} と、区分の合計の欄 {yen(groups の total)} が一致しません。」
- group が "guard" の項目の kind が "gold"・"bond" のどちらでもなければ「注意：守り資産の「{表示名}」に種類（金・債券）の指定がありません。」（その項目は金・債券の件数に数えない）

表示設定（asset-display）が JSON として読めないときは、注意の帯は出さず、すべての保有資産を「表示設定に無い」扱い（データの name・空の説明・区分の色）で表示する（確認スクリプトがこれを知らせる）。
