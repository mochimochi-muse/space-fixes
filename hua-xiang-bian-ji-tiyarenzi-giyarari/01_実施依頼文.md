# ギャラリー改修 実施依頼文（Stage 4・確定版）

対象：Space「画像編集チャレンジ ギャラリー」（slug: hua-xiang-bian-ji-tiyarenzi-giyarari）の index.html
経緯：Opus の先行設計（2026-11-22）→ Neon の壁打ちと実ファイル確認（2026-11-23）→ Sol のレビュー（2026-11-23）→ もちが実ファイルで裏取りして確定。

## 全体の原則
- 今回行うのは次の2点だけです。（A）★高評価の端末保存（固定キー化）、（B）作品データの1か所集約。
- A・Bに必要な内部変更と、指定する説明文の更新を除き、既存機能の操作・表示結果・保存互換性は一切変えないこと。特に次を維持すること：高速スクロールバー #fastScroll、指示線アノテーション #lbAnnoBox、ライトボックスのホイール拡縮・ドラッグ移動・近傍プリロード、URLハッシュ同期（restoreFromHash）、キュー（gallery-queue-v2、gallery-queue-v1 からの移行を含む）、組み合わせビルダーと下書き保存（gallery-combos-v1、gallery-combo-draft-v1）、モーダル一式、絞り込み・並び順（初期値「新しい順」）、カード表示モード（gallery-view-v1）、遅延描画。
- 作品データの転記は手で書き写さず、現在のファイルから機械的に抽出・変換すること（Bの手順）。

## A. ★高評価の保存
現行：var rated = {} に、ライトボックスの操作で idx（並び順の番号）をキーに保持するだけ。ページを開いている間だけ有効で、再読み込みで消える。
変更：
1. 保存先は localStorage のキー "gallery-rated-v1"。値は固定キー（itemKeys の文字列）の JSON 配列とする。
2. rated の初期化を buildItemKeys の直後（描画より前）で行う。localStorage から読み、JSON として読めない・配列でない場合は空として扱う。現在の作品に存在するキー（keyToIdx にあるもの）だけを rated に入れる（rated[固定キー] = true の形）。読み込みの際に保存内容を書き直さないこと。
3. 参照箇所の置き換え：rated[idx] → rated[keyOfIdx(idx)]、rated[r.idx] → rated[keyOfIdx(r.idx)]。対象は、カード描画後のフラグ反映（data-rate-for の hidden 切り替え）、syncRateUI、lbRate のクリック処理。カードの data-rate-for 属性（idx 基準）自体は変更しない。
4. lbRate のクリックで付け外しした直後に、rated のキー一覧を localStorage へ保存する。保存は try-catch で囲み、失敗してもページの操作が止まらないようにする。
5. 文言の更新：
   - コード内コメント「高評価（このページを開いている間だけ保持する、その場の印）」→「高評価（この端末のブラウザに保存する印）」
   - 使い方モーダルの一文「「☆ 高く評価する」は、気に入った場面へのその場の印です（このページを開いている間だけ保持されます）。」→「「☆ 高く評価する」は、気に入った場面への印です。印はこの端末のブラウザに保存され、同じブラウザで開けば次回も残ります。」
   - lbActionNote の文言（「現在 N 点が高評価」など）はそのまま。

## B. 作品データの集約
現行：本体スクリプト内に var SERIES = [...]、var ITEMS = [...]、ITEMS.push(...) ×2、var GROUPS = [...] が分かれて書かれている。
変更：
1. 現在のファイルから SERIES、ITEMS（push 2回を適用した後の全件）、GROUPS を機械的に抽出し、JSON に変換する。変換規約：文字列中の "<" は "\u003c" に置換する（</script> での途中終了を防ぐ）。プロパティ名・値・並び順は一切変えない。
2. 本体スクリプトより前に <script type="application/json" id="gallery-data"> ブロックを1つ置き、その中に {"series": [...], "items": [...], "groups": [...]} を入れる。items は1作品1行、series と groups も1要素1行で並べる。
3. 本体スクリプト側のデータ定義（var SERIES / var ITEMS / ITEMS.push ×2 / var GROUPS の各文）は削除し、代わりに冒頭で gallery-data の textContent を JSON.parse して SERIES・ITEMS・GROUPS に代入する。以後のコード（groupOfSeries の構築、buildItemKeys、統計の自動計算、描画）は現行のまま動くこと。
4. 件数の基準（2026-11-23 の抽出時点）：SERIES 37件、ITEMS 245件、GROUPS 5件（メンバー合計37）。buildItemKeys の出力（245件・出現順）が改修前と完全一致すること。改修後に gallery-data を再抽出・再パースし、改修前のデータと順序つきで全フィールドが一致することを確認してから公開すること。一致しない場合は公開しないこと。

## 対象外（今回やらないこと）

- サムネイル・原寸の追加生成（2026-11-23 の確認で、参照されている画像はすべて実在した）。
- 作業記録 JSON（assets/ 内の media-generation-*.json 10件）の移動（ページから未参照であることは確認済み。移動はもちが別途行う）。
