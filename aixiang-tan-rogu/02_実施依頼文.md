- **時刻（time）**：(d) のとおりです。
- **日付（date）**：「YYYY-MM-DD」の形だけを受け付けてください（今の add_session にこの点検がなければ足してください）。(c) の重複の点検で、同じ日を同じ日と見分けるためです。
- **題名（title）**：前後の空白を取ってから保存してください。空なら拒否します。

### (b) 「修正」「削除」の操作を足す
どちらも、add_session と同じく、操作（アクション）として足してください。画面に修正・削除のボタンは要りません（もちが記録するときと同じく、操作から使います）。どちらも1回に1件だけで、まとめて直す・まとめて消す操作は作らないでください。

#### update_session（修正）
渡すもの（例）：
```
{"id": 42, "model": "Opus", "note": "effort High"}
```
- `id` は必ず書きます。そのほかは、変えたい項目だけを書きます。書かなかった項目は変えません。
- 変えられる項目：partner, model, note, title, date, time, url。
- 空にできるのは time（時刻不明にする）、url（リンクを消す）、note だけです。url を空文字か null にしたら null で保存してください（今のデータでは、URLのない行は null です）。partner・model・title・date は空にできません。
- 本文（messages）と created_at は、この操作では変えません（本文の手直しは今回の対象外です）。
- 点検は (a-3)・(c)・(d) を add_session と同じに行い、合わなければ何も変えません。
- 返事：変えた項目ごとの「前」と「後」の値。id が見つからなければエラー。変わる項目が1つもなければ「変更なし」。

#### delete_session（削除）
消すと取り返しがつかないので、2段階にしてください。

1. **下見**：`{"id": 54, "title": "（その相談の題名）"}` のように、`confirm` を付けずに渡したときは、何も消さずに、その相談の中身をまるごと返してください（相手・モデル・題名・日付・時刻・URL・メモと、本文全部を add_session と同じ形で）。あわせて「まだ消していません」と返してください。
2. **実行**：`{"id": 54, "title": "（その相談の題名）", "confirm": true}` のときだけ消します。id と題名の**両方**が、保存されている値と合うとき（題名は前後の空白を除いて1文字も違わないとき）だけ消し、合わなければ何も消さずにエラーにしてください。

- **本文との関係**：相談を消すときは、その相談の本文（messages の session_id が同じ行）も一緒に消してください。相談と本文は1つの処理でまとめて消し、途中で失敗したら全部取り消してください（本文だけ残る、相談だけ残る、という状態を作らない）。今のテーブル定義には「相談を消すと本文も消える」仕組み（ON DELETE CASCADE）がないので、本文ははっきり指定して消してください。
- **返事**：消した相談の中身を、add_session と同じ形で返してください。間違えて消したときは、その返事を add_session に渡せば同じ内容を戻せるようにするためです（ただし id は新しい番号になります。消した番号は使い回されません）。

### (c) 重複を拒否する
- **追加のとき**：日付・題名・相手の3点が、すでにある1件とすべて同じなら拒否し、何も保存しないでください。返事に、ぶつかった相談の id と題名を出してください。
- **くらべ方**：日付はそのまま、題名は前後の空白を取って完全に同じか、相手は (a-3) の点検を通った値（決まった書き方の名前）でくらべます。(a-2) の書き換えがすんだあとの値とくらべるので、「Google Gemini」と「Gemini」のような書き方の違いで重複がすり抜けることはありません。
- **3点のうち1つでも違えば通します**。時刻とモデルは重複の判定に使いません。
  - 例：#42（Claude Code・Opus）と #43（Perplexity・Sol）は、日付・題名・時刻が同じですが、相手が違う別々の相談です。重複ではありません。2件ともそのまま残し、同じ形の追加（日付・題名が同じで相手が違う）も通るようにしてください。
- **修正のとき**：修正したあとの3点が、自分以外のどれか1件と同じになるときは拒否し、何も変えないでください。自分自身とくらべて同じ（3点を変えない修正）なのは問題ありません。
- データベース側に3点の一意制約を足すかどうかは、お任せします（足す場合も、拒否の返事は上のとおり分かりやすくしてください）。今のデータには、3点がそろう組はありません（確かめ済み）。

### (d) 時刻は「HH:MM」だけにする
- **入力**：add_session・update_session の時刻は、「HH:MM」（半角、2けた:2けた、00:00〜23:59。例：07:02）か空欄だけを受け付けてください。「7:02」「朝」「未明」「19時」などは拒否し、「時刻が分からないときは空欄にして、分かっていること（例：朝）はメモに『時刻：朝』のように書いてください」と返してください。それらしい時刻を作って入れる（自動で補う）ことはしないでください。
- **表示**：時刻が空欄の相談は、一覧と会話画面の見出しで「時刻不明」と出してください。
- **並び**：同じ日の中では、時刻不明の相談を、時刻のある相談より後ろ（その日の並びの最後）に置いてください。新しい順でも古い順でも同じです。同じ日に時刻不明が2件以上あるときは id の順にします（新しい順なら id の大きいほうが先、古い順なら小さいほうが先）。サーバーが返す並び（新しい順）も同じ決まりにしてください。
  - 「日付＋時刻」の文字でそのままくらべると、空欄は古い順でその日の先頭に来てしまいます。そうならないようにしてください。
  - 「やり取りの多い順」「タイトル順」の並びは今のままです。
- **既存の4件**：#8（未明）と #11（朝）は、「変える行の一覧」のとおり時刻を空欄にし、メモに「時刻：未明」「時刻：朝」を残します。#35・#36 は今も空欄なので、そのままです（メモに時刻のことは足しません）。
- **こう決めた理由**：
  - 「未明」「朝」から、それらしい時刻（たとえば 04:00）を作って入れると、本当に記録された時刻と見分けがつかなくなります。元の記録に分単位の根拠がないので、時刻欄は空欄にし、分かっていることだけをメモに残します。
  - 時刻欄を「HH:MM か空欄」だけにすると、並べ替えが確実になり、絞り込みや並びで書き方の揺れが起きません。
  - 時刻の分からない相談をその日の最後に置くのは、時刻のある相談の並び（何時ごろ、どの順で相談したか）を崩さないためです。

```python
for i, d, t, p, m, ti in new:
    why = []
    if p not in PARTNERS_NEW:
        why.append(f"相手「{p}」が3つの選択肢にない")
    if BAD_MODEL.search(m):
        why.append(f"モデル「{m}」に細かい設定・版番号が混ざっている")
    if t != "" and not HHMM.match(t):
        why.append(f"時刻「{t}」がHH:MMでない")
    print(f"  #{i} {d} {t or '（空欄）'} {p}・{m}「{ti}」 … " + ("ルールどおり（変えない行）" if not why else "要対応：" + "、".join(why)))
    if why:
        needs_work.append(i)
if needs_work:
    problems.append(f"増えた相談にルール外の行がある {needs_work}")

print()
print("== 5. 同じ日付・題名の組（相手を正規化してくらべる） ==")
groups = {}
for i, d, t, p, m, ti in rows:
    groups.setdefault((d, ti.strip()), []).append((i, NORM.get(p, p)))
dup_found = False
for (d, ti), v in groups.items():
    if len(v) > 1:
        same = len({p for _, p in v}) < len(v)
        dup_found |= same
        print(f"  {d}「{ti}」: " + "、".join(f"#{i}（{p}）" for i, p in v)
              + (" … 相手も同じ＝重複" if same else " … 相手が違うので重複ではない"))
if dup_found:
    problems.append("日付・題名・相手がそろう組がある")

print()
print("== 判定 ==")
if problems:
    print("出さない：" + "／".join(problems))
    print("→ 02 の「出す前の確かめ」の表にしたがって、01・02 を直してから、もう一度この確かめをする")
else:
    extra = f"（16:05より後の {len(new)} 件はルールどおりなので変えない行。適用後の見込みに足す）" if new else ""
    print("出してよい" + extra)
```

```python
"""適用後の確認（AI相談ログ）。改修前の控えと、適用後の写しを読み取り専用で開いてくらべる。
使い方: python3 -I check_after.py <控えのapp.db> <適用後の写しのapp.db> <02_実施依頼文.md>
"""
import hashlib, re, sqlite3, sys
from collections import Counter
from pathlib import Path

before_path, after_path, req_path = sys.argv[1], sys.argv[2], sys.argv[3]
EMPTY = "（空欄）"
HHMM = re.compile(r"^([01][0-9]|2[0-3]):[0-5][0-9]$")

def open_ro(p):
    return sqlite3.connect(Path(p).resolve().as_uri() + "?mode=ro", uri=True)

# 02 の「変える行の一覧」を読む（Claudeの差し替えをしたあとの02を渡すこと）
table = {}
in_section = False
for line in open(req_path, encoding="utf-8"):
    if line.startswith("#"):
        in_section = line.startswith("### 変える行の一覧")
        continue
    if in_section and re.match(r"^\| \d+ \|", line):
        c = [x.strip() for x in line.rstrip("\n").strip("|").split("|")]
        v = lambda s: "" if s == EMPTY else s
        table[int(c[0])] = dict(date=c[1], title=c[2], pb=c[3], pa=c[4], mb=c[5], ma=c[6],
                                tb=v(c[7]), ta=v(c[8]), note=v(c[9]))

b, a = open_ro(before_path), open_ro(after_path)
a_cols = [r[1] for r in a.execute("PRAGMA table_info(sessions)")]
problems = []

print("== 0. 読み込み ==")
print("02 の「変える行の一覧」:", len(table), "行")
if "note" not in a_cols:
    print("適用後のデータベースにメモ欄（note）がない → ここで止める")
    sys.exit(1)

Q = "SELECT id, partner, model, title, date, time, url, created_at{} FROM sessions ORDER BY id"
bs = {r[0]: r for r in b.execute(Q.format(""))}
as_ = {r[0]: r for r in a.execute(Q.format(", note"))}

print()
print("== 1. 相談の件数 ==")
print(f"控え: {len(bs)} 件 ／ 適用後: {len(as_)} 件")
gone = sorted(set(bs) - set(as_))
extra = sorted(set(as_) - set(bs))
print("控えにあって適用後にない id（消えた）:", gone or "なし")
print("適用後にだけある id（控えのあとに増えた）:", extra or "なし")
if gone:
    problems.append(f"消えた相談がある {gone}")
if extra:
    problems.append(f"控えのあとに増えた相談がある {extra}（試しの行の消し忘れでないか）")

print()
print("== 2. 本文（messages） ==")
def msgs(con):
    return {r[0]: (r[1], hashlib.sha256(repr(r[1:]).encode()).hexdigest())
            for r in con.execute("SELECT id, session_id, seq, role, body FROM messages")}
mb, ma = msgs(b), msgs(a)
print(f"控え: {len(mb)} 通 ／ 適用後: {len(ma)} 通")
changed_m = [k for k in mb if k in ma and mb[k] != ma[k]]
lost_m = [k for k in mb if k not in ma]
new_m = [k for k in ma if k not in mb]
print("中身が変わった本文:", len(changed_m), "通 ／ 消えた本文:", len(lost_m), "通 ／ 増えた本文:", len(new_m), "通")
orphan = a.execute("SELECT COUNT(*) FROM messages WHERE session_id NOT IN (SELECT id FROM sessions)").fetchone()[0]
print("相談のない本文（消し残り）:", orphan, "通")
if changed_m or lost_m or new_m or orphan:
    problems.append("本文が控えと違う")

print()
print("== 3. 1件ずつ（一覧どおりに変わり、ほかは変わっていないか） ==")
bad = []
for i, r in bs.items():
    if i not in as_:
        continue
    _, p, m, ti, d, t, url, ca = r
    x = as_[i]
    # 変えてはいけないもの
    if (x[3], x[4], x[6], x[7]) != (ti, d, url, ca):
        bad.append(f"#{i} 題名・日付・URL・作成時刻のどれかが変わった")
    if i in table:
        e = table[i]
        if (e["pb"], e["mb"], e["tb"], e["date"]) != (p, m, t, d):
            bad.append(f"#{i} 02の一覧の「今」の値が控えと合わない（02と控えのどちらかが古い）")
        want = (e["pa"], e["ma"], e["ta"], e["note"])
    else:
        want = (p, m, t, "")
    got = (x[1], x[2], x[5], x[8] or "")
    if got != want:
        bad.append(f"#{i} 期待 {want} ／ 実際 {got}")
missing_rows = sorted(set(table) - set(bs))
if missing_rows:
    bad.append(f"02の一覧にあるのに控えにない id {missing_rows}")
print("食い違い:", "なし" if not bad else "")
for s in bad:
    print("  " + s)
if bad:
    problems.append("一覧どおりになっていない行がある")

print()
print("== 4. 適用後の表記（数） ==")
rows = list(as_.values())
for name, idx in (("相手", 1), ("モデル", 2)):
    cnt = Counter(r[idx] for r in rows)
    print(f"[{name}] {len(cnt)} 種：" + "、".join(f"{k} {v}" for k, v in sorted(cnt.items(), key=lambda kv: (-kv[1], kv[0]))))
print("メモ欄に何か入っている:", sum(1 for r in rows if r[8]), "件")
empty_t = [r[0] for r in rows if r[5] == ""]
odd_t = [r[0] for r in rows if r[5] != "" and not HHMM.match(r[5])]
print("時刻が空欄（画面では「時刻不明」）:", empty_t)
print("時刻がHH:MMでも空欄でもない:", odd_t or "なし")
if odd_t:
    problems.append("HH:MMでない時刻が残っている")

print()
print("== 5. 重複（日付・題名・相手） ==")
k3 = Counter((r[4], r[3].strip(), r[1]) for r in rows)
dups = [k for k, v in k3.items() if v > 1]
print("3点がそろう組:", dups or "なし")
k2 = {}
for r in rows:
    k2.setdefault((r[4], r[3].strip()), []).append(f"#{r[0]}（{r[1]}）")
for k, v in k2.items():
    if len(v) > 1:
        print("日付・題名だけ同じ組（残っていてよい）:", "、".join(v))
if dups:
    problems.append("重複がある")

print()
print("== 判定 ==")
print("すべて合格" if not problems else "不合格：" + "／".join(problems))
```
